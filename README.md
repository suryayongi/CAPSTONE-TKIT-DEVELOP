# Capstone TKIT Al-Madani

Repository proyek Capstone untuk TKIT Al-Madani.

## Struktur Direktori

- `frontend/` - Aplikasi antarmuka pengguna (React / Vite / Tailwind CSS).
- *(Direktori backend atau layanan lainnya akan ditambahkan di root ini seiring perkembangan proyek)*

## Memulai Pengembangan (Frontend)

1. Masuk ke direktori frontend:
   ```bash
   cd frontend
   ```
2. Pasang dependensi:
   ```bash
   npm install
   ```
3. Jalankan server pengembangan:
   ```bash
   npm run dev
   ```
